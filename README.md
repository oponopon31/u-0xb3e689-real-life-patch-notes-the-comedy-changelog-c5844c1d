A one-line software patch note for a bug in real life, written in the
terse register of a real release note. The program writes the single
chosen line (at most 160 characters) plus one trailing newline to
`entry.txt`, validates it, then re-reads the file and prints the
character count, byte count, and SHA-256 digest.

## Run

```sh
python3 main.py
```

By default the output goes to `$MAKEFUN_OUTPUT_DIR` when set, otherwise
`/output` when writable, otherwise the current working directory.
